# Голосовой помощник для учебного расписания

Браузер записывает вопрос, сервер распознаёт речь, уточняет день и время с помощью модели, сверяется с расписанием и синтезирует ответ. Завтра в 18:30 свободно, в 19:00 занято. На послезавтра данных нет. В приложении доступна только проверка расписания.

## Локальный запуск

Нужны Node.js 22.12 или новее, браузер с доступом к микрофону и настроенные провайдеры. Из PowerShell в папке проекта выполните:

```powershell
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

Укажите ключ в `.env` и выберите конфигурацию провайдера. В примере для OpenAI достаточно заполнить `LLM_API_KEY`, если вашей учётной записи доступны указанные модели. Затем выполните:

```powershell
npm run build
npm start
```

Откройте [локальное приложение](http://127.0.0.1:3000). Сервер слушает loopback-интерфейс. При облачной конфигурации нужны интернет и ключи выбранных API. Для запуска без интернета укажите локальные сервисы, которые реализуют указанные ниже HTTP-контракты. После изменений в `.env` перезапустите сервер.

| Настройка | Назначение |
| --- | --- |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | Адрес OpenAI-совместимого API с префиксом версии, ключ и модель для `/chat/completions`. |
| `STT_BASE_URL`, `STT_API_KEY`, `STT_MODEL` | Адрес, ключ и модель распознавания речи. |
| `TRANSCRIPTION_MODE` | `transcriptions` отправляет файл в `/audio/transcriptions`. `chat_audio` использует `input_audio` в `/chat/completions`. |
| `TTS_PROVIDER` | `openai` для OpenAI-совместимого `/audio/speech`, `elevenlabs` для ElevenLabs и `espeak` для локального синтеза eSpeak NG. |
| `TTS_BASE_URL`, `TTS_API_KEY`, `TTS_MODEL`, `TTS_VOICE` | Адрес, ключ, модель и голос синтеза. Облачный провайдер должен возвращать поток PCM S16LE, 24 кГц, моно. В режиме `espeak` используется только `TTS_VOICE`, по умолчанию `ru`. |
| `PORT` | Локальный порт, по умолчанию 3000. |

В режиме `openai` пустые адреса STT и TTS наследуются от `LLM_BASE_URL`. Пустой ключ наследуется, если протокол, хост и порт совпадают. Для локальных сервисов на loopback ключ можно оставить пустым.

### VseLLM с локальной озвучкой

В `.env` укажите ключ VseLLM в `LLM_API_KEY` и следующие значения:

```dotenv
LLM_BASE_URL=https://api.vsellm.ru/v1
LLM_MODEL=google/gemini-3.1-flash-lite
STT_MODEL=google/gemini-3.1-flash-lite
TRANSCRIPTION_MODE=chat_audio
TTS_PROVIDER=espeak
TTS_VOICE=ru
```

Адрес и ключ STT можно оставить пустыми для наследования от LLM. Gemini распознаёт речь и определяет параметры расписания. eSpeak NG генерирует русскую озвучку на компьютере по предложениям и отправляет PCM 22,05 кГц в тот же поток. Голос eSpeak NG звучит механически. [Gemini 3.1 Flash Lite в VseLLM](https://vsellm.ru/models/google/gemini-3.1-flash-lite), [языки eSpeak NG](https://github.com/espeak-ng/espeak-ng/blob/master/docs/languages.md).

### Облачная озвучка

Согласно документации OpenAI, модель `gpt-4o-mini-tts` и другие модели `/audio/speech` из примера выводятся из эксплуатации 6 января 2027 года. Цепочка поддерживает замену TTS независимо от LLM и STT. Для ElevenLabs оставьте `TTS_BASE_URL` пустым, укажите собственный `TTS_API_KEY`, установите `TTS_PROVIDER=elevenlabs`, `TTS_MODEL=eleven_flash_v2_5` и подставьте ID подходящего голоса в `TTS_VOICE`. [OpenAI Speech API](https://developers.openai.com/api/docs/guides/text-to-speech), [ElevenLabs Streaming TTS](https://elevenlabs.io/docs/api-reference/text-to-speech/stream).

## Как проверить

1. Нажмите «Начать разговор» и разрешите доступ к микрофону. После появления статуса «Слушаю вас» скажите «Можно завтра после шести?» и нажмите «Отправить вопрос». Запись также автоматически отправляется через 30 секунд.
2. Убедитесь, что в диалоге появились вопрос и ответ, а голос сообщает про свободные 18:30 и занятые 19:00.
3. Нажмите «Записать вопрос» и спросите «А в девятнадцать ноль-ноль?». Помощник использует день из предыдущей реплики и сообщает, что время занято.
4. Спросите «Что есть на послезавтра?». Ответ должен сообщить об отсутствии данных. Запрос «Запишите меня завтра в 18:30» должен вернуть только результат проверки и пояснение о возможностях помощника.
5. Нажмите «Завершить разговор» во время воспроизведения. Звук прекращается. При новом запуске диалог пуст, а предыдущий день забыт.

«Сервер подключён» означает, что веб-приложение связалось с сервером и сервер принял настройки. Доступ к модели проверяется при обработке вопроса. При сбое можно повторно обработать последнюю запись или записать вопрос заново.

## Архитектура

- **React и Vite** отвечают за интерфейс, `MediaRecorder` — за запись, а Web Audio — за воспроизведение. История и контекст хранятся в памяти браузера на время разговора.
- **Hono и Node.js** обслуживают локальный API. Модель возвращает параметры поиска. Сервер проверяет их, читает учебное расписание из `server/schedule.js` и составляет текст для озвучки по фактическому результату. Аудио и расшифровка передаются настроенным провайдерам в ходе обработки, а само приложение не пишет записи и реплики на диск.
- **Потоковый вариант — голосовой ответ.** Сервер читает PCM от TTS по мере поступления и отправляет фрагменты вместе с событиями состояния через HTTP-поток NDJSON. Браузер начинает воспроизводить их после короткой буферизации. Текст ответа показывается целиком после проверки расписания.

Серверные тесты и сборка:

```powershell
npm test
npm run build
```

## Перенос на ChatGPT Sites

Сборка клиента находится в `dist/client`. Браузер обращается к API на том же домене. Модуль `server/api.js` использует Fetch API, Web Streams и Hono. Для публикации можно подключить его к Fetch-обработчику Cloudflare Worker, добавить выдачу клиентских файлов и собрать серверную часть в `dist/server/index.js`. Для озвучки на Sites выберите облачный TTS. Локальный eSpeak NG подключается в Node.js. На Sites значения, включая ключи, задаются как серверные переменные и секреты.

Перед публикацией нужно проверить разрешение на микрофон в браузере, воспроизведение и прохождение NDJSON через хостинг, а также ограничить доступ к API, который расходует квоту провайдеров.
